CCNA - Cisco Certified Network Associate

About Course:
CCNA is a professional networking course by Cisco. This course teaches you the fundamentals of computer networks, switching, routing and real-world network configuration.

Duration: 3 Months

Mode: Physical & Online

Course Modules

  • Introduction to Computer Networking
  • OSI & TCP/IP Models
  • IPv4 & IPv6 Addressing
  • Subnetting & IP Calculation
  • Switching Fundamentals
  • VLAN & Trunk Configuration
  • Routing Fundamentals
  • Static & Dynamic Routing
  • DHCP, DNS & NAT
  • Cisco Router & Switch Configuration
  • Cisco Packet Tracer Practical Labs
  • Basic Network Security

Learning Outcomes

  • Understand complete networking concepts
  • Configure Cisco routers and switches
  • Create and troubleshoot networks
  • Prepare for CCNA certification
  • Start a career as Network Engineer

Career Opportunities

  • Network Engineer
  • IT Support Engineer
  • System Administrator
  • Network Technician
